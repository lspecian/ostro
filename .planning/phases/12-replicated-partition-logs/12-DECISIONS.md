Record `base=$(git rev-parse HEAD)` before editing; before committing, check `git diff --quiet "$base" HEAD -- <file>`; if another executor committed to it meanwhile, re-apply your hunk on the new HEAD content, rebuild and re-test.

## Commit procedure (every plan)

Executors share one working tree with other executors, so commits go through a **private index** and add only the plan's own files:

```bash
idx="$(git rev-parse --git-dir)/index-12-NN"; rm -f "$idx"
GIT_INDEX_FILE="$idx" git read-tree HEAD
GIT_INDEX_FILE="$idx" git add -- <this task's files, listed explicitly>
GIT_INDEX_FILE="$idx" git commit -q -F "$msgfile"   # message ends with the Co-Authored-By line
rm -f "$idx"; git reset -q -- <the same files>       # resync the shared index for these paths only
```

Never `git add -A`, `git add .`, `git add -u`, `git commit -a`, `git stash`, `git checkout -- <path>` on files you do not own, or `git reset --hard`. Messages end with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`. No remotes, no pushes. Never run gsd-tools mutators (`state advance-plan`, `roadmap update-plan-progress`, `phase complete`, `requirements mark-complete`, `commit`).

## Worktree procedure (gates)

Plan-level gates run in a **detached scratch worktree** at the plan's last commit, so other executors' uncommitted edits never leak into the result:

```bash
wt="/tmp/ostro-wt-12-NN"; git worktree add --detach "$wt" HEAD
( cd "$wt" && CARGO_TARGET_DIR=/tmp/ostro-wt-target bash scripts/ci-local.sh --no-musl )
git worktree remove --force "$wt"
```

`/tmp/ostro-wt-target` is shared across plans to save rebuilds (cargo's build lock serialises concurrent use). Record the worktree HEAD and the step timings in the SUMMARY. Task-level verifies run in the main tree.
