<startup_sequence>
Node::open (Leader mode):
0. `<data>/node.toml`: if absent write `format_version = 1\npartitions = <P>\n` (tmp + fsync + rename + dir fsync); if present parse these two keys (tiny hand parser — Phase 4 may switch to the toml crate) and compare P → `PartitionCountMismatch`. Event NodeFileChecked.
1. Open every state store (`PartitionStore::open`, in parallel via spawn_blocking). A store error (incl. PartitionCountMismatch in meta) → that slot Failed. Floor = meta.applied. Event StateOpened.
2. `LogNode::open(LogNodeConfig{wal_dir: <data>/wal, ..}, &floors)`; per-slot recovery error → slot Failed with the error text (it names segment/byte/offsets). Event LogRecovered.
3. Validate: `applied > leo` → Failed("state ahead of log: rebuild the state store"); `applied < log_start` → Failed("snapshot required (Phase 8)"). Event Validated.
4. Spawn the machine with `set_emit_actions(false)`; `wait_applied(HW - 1)` (replay [applied, HW)); event CaughtUp.
5. Term: `epoch = next_term_epoch(leadership.epoch_floor(p), log.epochs().latest())`; `log.set_role(Leader{epoch})`; `handle.set_epoch(epoch)`; `submit_one(LeaderAnnounced{epoch, node_id, announced_at_ms: clock.now_ms()})` must return Accepted (else slot Failed). Event TermStarted (offset = the LA offset).
6. `set_emit_actions(true)`; `barrier.open()`; event BarrierOpened; register the handle in the InProcessRouter; then (after ALL partitions reached step 6, so the router is complete) `leader::spawn_all(ctx)`; event LeaderServicesStarted.
Inspect mode stops after step 4 (no LA append, barrier stays closed, no leader services).
Events are recorded in a `Mutex<Vec<StartupEvent>>` in order of occurrence per partition.
</startup_sequence>
