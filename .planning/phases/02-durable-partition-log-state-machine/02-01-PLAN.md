fjall 3.1.13 API (verified in the S3 spike, spikes/s3-redb-bench/src/main.rs):
```rust
use fjall::{Database, Keyspace, KeyspaceCreateOptions, PersistMode};
let db = Database::builder(path).worker_threads(1).max_journaling_size(64 << 20).cache_size(16 << 20).open()?;
let ks: Keyspace = db.keyspace("meta", KeyspaceCreateOptions::default)?;
let mut b = db.batch(); b.insert(&ks, key, value); b.remove(&ks, key); b.commit()?;
db.persist(PersistMode::SyncAll)?;
ks.get(key)? -> Option<Slice>;  ks.iter(); ks.range(a..b); ks.prefix(p);
```
Builder knobs: `worker_threads(n)` (default min(cores,4)), `max_journaling_size(bytes)` (default 512 MiB, panics < 64 MiB), `cache_size(bytes)` (default 32 MiB). Keyspace option: `KeyspaceCreateOptions::default().max_memtable_size(bytes)`.
