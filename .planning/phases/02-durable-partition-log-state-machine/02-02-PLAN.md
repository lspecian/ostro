P1 (poison), following 02-RESEARCH "Vendored patch P1":
- `error.rs`: add `#[error("WAL partition poisoned: {0}")] Poisoned(String)`.
- `PartitionQueue`: add `poisoned: AtomicBool` and `durable_len: AtomicU64` (bytes of the active segment known durable).
- `commit_batch`: replace the `write_all(..).await?; sync_all().await?;` pair with a match. On Err: set `poisoned`, best-effort `set_len(durable_len)` on the active segment (ignore its error, log it), clear the tail cache, send `Err(WalError::Poisoned(reason))` to every waiter in the batch AND drain `queue.pending` failing every waiter, do NOT advance `committed_through`, do NOT invoke the commit callback, return `Err(WalError::Poisoned(reason))`. On Ok: update `durable_len` with the post-batch segment length.
- Worker loop: on `Err(WalError::Poisoned(_))` from `commit_batch` log at `error!` and `return` (stop the worker). Other errors keep the existing behaviour but must also never have produced an Ok for a waiter.
- `enqueue_with_receipt`, `enqueue_nowait` (and `append`/`append_enqueued` if they bypass those): if `queue.poisoned.load(SeqCst)` return `Err(WalError::Poisoned(..))` before queueing.

- Add `pub fn is_poisoned(&self, topic: &str, partition: i32) -> bool` on `GroupCommitWal` (Ostro's ReplicatedLog health reads it).
