<timer_algorithm>
State: `window: BTreeSet<(u64 due, RunId, u64 op)>`, `horizon: u64` — invariant: every timer row with `due < horizon` is in the window.
refill(now): `rows = reader.range(Timers, timer_key(0, MIN_RUN, 0), timer_key(now + span, MIN_RUN, 0), window_max)`; window = rows; `horizon = if rows.len() == window_max { last_due } else { now + span }` (when truncated, drop entries with `due == last_due` from the window so the invariant holds, or keep them all and set horizon = last_due + 1 only if no more rows share that due — pick one and test the boundary).
Actions: `ScheduleTimer{due,..}` with `due < horizon` → insert; if `window.len() > window_max` pop the largest and set `horizon = popped.due` (re-apply the boundary rule). `CancelTimer` → remove.
Loop: if window empty or `now + span/2 >= horizon` → refill. Take all entries with `due <= now` (≤ fire_batch), submit one batch of `TimerFired{run, op, due_at_ms: due, fired_at_ms: now}`, remove each from the window after its outcome (Accepted or Duplicate); a submit error → partition failing → exit. Otherwise sleep `min(earliest_due - now, 50 ms)` (real time; works with ManualClock tests) or wake on an action / shutdown. Wall clock is used only here (G7). Metrics: gauge `ostro_timer_window_entries`, counter `ostro_timers_fired_total`.
</timer_algorithm>

<retention_algorithm>
Every `interval` (first pass after one interval): `ckpt = machine.force_checkpoint().await?` (forces persist(SyncAll) and returns the durable applied offset); `floor = min(ckpt, cfg.snapshot_floor, cfg.retention_floor.unwrap_or(Offset(u64::MAX)))`; `permit = ctx.barrier.mint(floor)?` (NotReady → log and skip); `new_start = log.trim_prefix(permit).await?`; `info!(partition, floor, new_start, "retention pass")` on EVERY pass, including "nothing to trim". Never run before the barrier is open (spawn happens after it, and mint re-checks).
</retention_algorithm>
