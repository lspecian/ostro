<semantics>
Epoch gate (first, for every command): `LeaderAnnounced{epoch}` is Accepted iff `epoch > cur.epoch && env_epoch == epoch` → `cur.meta.epoch = epoch`, push `(epoch, off)` to `epoch_history`; else Rejected(StaleEpoch{current}). Any other command with `env_epoch != cur.epoch` → Rejected(StaleEpoch{current}).
StartRun (`start_run`): run_id must parse and `run.partition() == cur.partition` (else WrongPartition / Invalid(BadRunId)); input inline oversize → PayloadTooLarge; if idempotency_key non-empty: ONE read of `dedupe_key(workflow, key)` → hit: ReturnExisting → Duplicate{existing}, Reject → Rejected(IdempotencyConflict{existing}); miss → insert dedupe row. If key empty: ONE read of `run_key` → exists → Duplicate{existing: same}. Insert RunRecord (status Ready if `ready_at_ms <= requested_at_ms` else Scheduled), payloads(run, 0) = prost-encoded input, `rng_seed` stored as given. Ready: insert `ready_key(queue, priority, ready_at, run)` → ReadyValue{concurrency_key} + `run.ready = Some(slot)` + Action::EnqueueReady. Scheduled: insert `timer_key(ready_at, run, START_DELAY_OP)` + Action::ScheduleTimer. Parent (if any) is stored in `run.parent`.
AttemptGranted: one read (run). Not found → RunNotFound; terminal → RunTerminal; `token.epoch != cur.epoch` → StaleEpoch; `Some(token) <= run.current_attempt` → Fenced{current}; else `current_attempt = token`, status Running, blind-remove the ready row from `run.ready`, `run.ready = None`.
EventsAppended: one read (run). Order of checks: missing token → Invalid(MissingToken); not found → RunNotFound; terminal → RunTerminal; `token.epoch != cur.epoch` → StaleEpoch; `Some(token) != run.current_attempt` → Fenced{current}; `from_seq != run.next_seq` → SeqMismatch{expected}; events not contiguous from from_seq → Invalid(EventsNotContiguous); any event or derived payload inline oversize → PayloadTooLarge. Only after ALL checks pass, write: events rows (stored value = prost-encoded JournalEvent), `next_seq += n`, then each Derived in order: ScheduleTimer → insert timer row + Action; CancelTimer → blind remove timer row (key from op + due_at_ms carried in the intent: no read) + Action; SendMessage → `emit` (if the msg is StartChild also insert `children_key(run, child)` and `run.children += 1`); EnqueueReady → ready row + `run.ready` + status Ready + Action; CompleteRun → status terminal, payloads(run, 1) = result, blind-remove ready row, Action::RunCompleted; if `run.parent` is set, `emit(ChildCompleted{parent_run, child_run, op, status, result})`. Write the run record once at the end.
Validation is all-or-nothing per command (check everything before the first write), so a rejection never leaves partial writes in the overlay.
</semantics>
