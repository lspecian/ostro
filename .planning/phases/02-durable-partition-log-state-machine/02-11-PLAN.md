<apply_thread>
Loop (std::thread; use `rt.block_on` only for log I/O and HW waits):
1. `hw = *hw_rx.borrow()`; if `hw <= cur.next` → block on `hw_rx.changed()` (also wake on control messages / shutdown / log health change; use a small `select!` inside `block_on`).
2. `batches = log.read(cur.next, hw, max_chunk_bytes)` (verified); cap the chunk at `max_chunk_cmds`. Invariant check: every batch `end() <= hw` — violation → Failed("apply passed HW") (never silently continue).
3. `let mut b = store.batch(); outcomes = apply_chunk(&mut b, &mut cur, &batches, &mut actions)?; b.commit(&cur.meta_update())?;` — any Err → health Failed, `acks.fail_all`, thread exits (no retry; reopen = replay from the state's own applied_offset).
4. `applied_tx.send(cur.next)`; `acks.resolve(&outcomes, cur.next)` (AFTER commit); if emit_actions → broadcast `Arc<Vec<Action>>` (ignore no-receiver errors).
5. Checkpoint if `batches_since >= checkpoint_batches || last_ckpt.elapsed() >= checkpoint_every || forced` → `store.checkpoint(cur.next)?` → `durable_tx.send(cur.next)`. `Instant::now` is allowed here with `#[allow(clippy::disallowed_methods)]` and a comment: the checkpoint decision is wall-clock driven but never changes logical state (digest excludes checkpointed_offset).
6. Watch `log.health()`: Failed → machine Failed, fail_all.
Graceful shutdown: drain to the current HW, final checkpoint, exit. Metrics (facade): `ostro_apply_batches_total`, `ostro_apply_commands_total`, `ostro_apply_batch_seconds` histogram, `ostro_state_checkpoint_seconds` histogram, labelled by partition.
</apply_thread>

<submit_path>
`submit`: encode commands (`encode_command`), `log.append(self.epoch(), bytes)` → receipt (position fixed), `acks.register(receipt.base, receipt.last)`, then await all receivers while also watching machine health (select!) → outcomes. PendingAcks is a two-sided rendezvous: if apply resolves an offset before register (possible: fsync and apply can finish before the submitter registers), the outcome waits in `ready`; entries older than `applied - ACK_RETAIN` are evicted, and registering an evicted offset yields `PartitionError::AckLost` (outcome unknown, never Ok). `grant_attempt`: read the run (StoreReader), next token = `{epoch: self.epoch(), n: if current.epoch == epoch { current.n + 1 } else { 1 }}`; submit AttemptGranted; Accepted → Ok(token); Rejected(r) → Err(Rejected(r)).
</submit_path>
