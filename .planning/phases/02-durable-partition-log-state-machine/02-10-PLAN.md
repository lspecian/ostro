<semantics>
InboundBatch{src, msgs} (on the target):
1. Validate before writing: `src < cur.count` (else Invalid(MissingField) or a new `InvalidCode::BadSource` appended at the END of the enum — outcome codes are append-only); each msg has a body; skip the leading msgs with `seq <= seen = inbound_seen[src]` (default 0); the remaining seqs must be exactly `seen+1, seen+2, …` — otherwise `Rejected(SeqGap{expected: seen+1, found})` with no writes. If nothing remains → `Duplicate{existing: None}`.
2. Process each new msg in order, then set `inbound_seen[src] = last seq`. Message-level misses (target run unknown/terminal) are deterministic drops — the seq is still consumed. Outcome Accepted.
Per kind (target partition):
- StartChild{start}: `start_run(start, dedupe = None)` (the child run_id is unique; a resend hits the runs-row check → Duplicate, consumed).
- ChildCompleted{parent_run, child_run, op, status, result}: read parent; if present and non-terminal → inbox `ChildCompleted` at `inbox_key(parent, inbox_next++)`, remove `children_key(parent, child)`, `children -= 1`, make ready (below). Else drop.
- Signal{target_run, name, payload}: read run; non-terminal → inbox `Signal`, make ready. Else drop.
- CancelRun{target_run, reason}: read run; non-terminal and `!cancel_requested` → `cancel_requested = true`, inbox `CancelRequested`, make ready, `Action::CancelRequested`, then `range_prefix(Table::Children, children_prefix(run))` and `emit(CancelRun{child, reason})` for every child (children may live in any partition). Already requested → drop (no second cascade).
- CronStart{schedule_id, fire_time_ms, start}: `start_run(start, dedupe = Some((format!("__cron/{schedule_id}"), fire_time_ms.to_be_bytes().to_vec())))` with ReturnExisting semantics → each (schedule, fire_time) starts exactly once.
"Make ready": if status is Scheduled → Ready and insert the ready row + `run.ready` + Action::EnqueueReady; if already Ready or Running → no new ready row (Running runs see the inbox on their next activation; dispatch wake-up policy is Phase 4).
OutboxTruncated{target, upto} (on the source): `upto <= truncated[target]` → Duplicate; `upto >= next_seq[target]` (never emitted) → Rejected(Invalid(TruncateBeyondEnd)) (append the variant at the END of InvalidCode); else blind-remove `outbox_key(target, s)` for s in `truncated+1 ..= upto`, set `truncated[target] = upto`, Accepted.
TimerFired{run, op, due_at_ms, fired_at_ms}: ONE read of `timer_key(due, run, op)`; absent → Duplicate (idempotent; a new leader may re-fire). Present → remove it; read run (second read — allowed for TimerFired); terminal → Accepted with no further effect; `op == START_DELAY_OP` → Scheduled → Ready + ready row + EnqueueReady; otherwise inbox `TimerFired{op, fired_at_ms}` + make ready. Wall clock never enters apply: `fired_at_ms` comes from the command.
</semantics>
