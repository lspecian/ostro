**Status:** adopted by the planner on 2026-11-19. The project runs in YOLO + auto_advance mode, so there is no blocking decision checkpoint. **User-review items** (07-01 flags them in STATE.md Pending Todos as `[USER REVIEW]`):
- **D-W3:** effects of remote runs execute on the leader; secrets never reach workers. WORK-01's "per-(run, attempt) secret resolution" is met on the leader. The fallback (worker-side effects plus a `ResolveSecret` RPC) costs about 3 more plans.
- **D-W8:** client-listener TLS default `auto`. A loopback listener stays plaintext; a non-loopback dev listener is self-signed; the server profile refuses to start without `files`/`acme` unless `allow_self_signed = true`.
- **D-W11:** QA-03 is judged as **exactly one charge per idempotency key** (`MockProvider::charges(key) == 1`), 0 lost effects and 0 sends from fenced sessions. Raw `requests(key) > 1` is reported and attributed to leader kills inside the send window or to 409-in-progress retries.

## Commit procedure (every plan)

Executors share one working tree with Phase 8 and late Phase 4/5/6 executors, so commits go through a **private index** and add only the plan's own files:

```bash
idx="$(git rev-parse --git-dir)/index-07-NN"; rm -f "$idx"
GIT_INDEX_FILE="$idx" git read-tree HEAD
GIT_INDEX_FILE="$idx" git add -- <this task's files, listed explicitly>
GIT_INDEX_FILE="$idx" git commit -q -F "$msgfile"   # message ends with the Co-Authored-By line
rm -f "$idx"; git reset -q -- <the same files>       # resync the shared index for these paths only
```

Never `git add -A`, `git add .`, `git add -u`, `git commit -a`, `git stash`, `git checkout -- <path>` on files you do not own, or `git reset --hard`. Messages end with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.
