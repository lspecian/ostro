  <files>crates/ostro-partition/src/apply/lifecycle.rs, crates/ostro-partition/tests/apply_lifecycle.rs</files>
  <behavior>
    - `on_start`:
      - run_timeout_ms > 0 → insert timer `(created_at_ms + run_timeout_ms, run, RUN_TIMEOUT_OP)`;
      - schedule_to_start_ms > 0 → `rec.s2s_due_ms = ready_at_ms + s2s` and insert `(s2s_due_ms, run, SCHEDULE_TO_START_OP)`.
    - `on_attempt_granted`: the first grant (current_attempt was None) deletes the S2S row by key `(rec.s2s_due_ms, run, SCHEDULE_TO_START_OP)` and sets `s2s_due_ms = 0`. Use `s2s_due_ms`, not `ready_at`, because the ready state is cleared at grant and terminate (W13).
    - `on_reserved_timer`:
      - RUN_TIMEOUT on a non-terminal run → `hard_stop(TimedOut, "run_timeout")`;
      - S2S on a never-granted, non-terminal run → `hard_stop(TimedOut, "schedule_to_start")`;
      - otherwise delete the row and accept;
      - row absent → Duplicate (existing semantics).
    - `hard_stop(status, reason)`, shared by Terminate and the timeouts:
      - set the status, terminal_reason and completed_at_ms;
      - remove the Ready and Running rows;
      - journal `RunTerminated{reason}` via `journal_input` only when next_seq > 0, WITHOUT a wake (terminal);
      - emit `Action::RunCompleted{status}`;
      - send ChildCompleted to the parent if there is one (same path as CompleteRun);
      - cascade graceful CancelRun to the children;
      - set `resumable = true` (D1: Terminated and TimedOut are resumable);
      - call `terminal::on_terminal`.
    - TerminateRun: unknown → RunNotFound, terminal → RunTerminal, otherwise hard_stop(Terminated, reason).
    - `on_terminal` (lifecycle part): delete the RUN_TIMEOUT row by key (due = created_at_ms + run_timeout_ms) and the S2S row by `rec.s2s_due_ms` when it is non-zero, then arm EXPIRE_OP at `completed_at_ms + retention_ms` when retention_ms > 0.
    - Tests:
      - timeout on a Scheduled (sleeping) run;
      - timeout on a Running run (RunCompleted action emitted, so the dispatcher can revoke in 05-11);
      - S2S fires before the grant → TimedOut, and after the grant → no-op;
      - terminate before start → no event at seq 0;
      - terminate mid-run → RunTerminated is the last event;
      - normal completion removes the timeout rows;
      - an append after terminate is rejected with RunTerminal (existing token check).
  </behavior>
