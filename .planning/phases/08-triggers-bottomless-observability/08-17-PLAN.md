  <behavior>
    - host/log.rs: after the existing replay check and per-activation bound, build a `GuestLogRecord` (with trace/span ids from `activation_span_context()` when valid) and call `sink.guest_log(rec)`. The existing tracing emission moves into the server sink. The engine keeps a fallback `tracing` event only when no sink is configured (engine tests), with fields as a JSON string under `guest.fields`.
    - `GuestLogSink::emit(rec)` applies, in order:
      1. the node token bucket (5,000/s) → drop reason `node_rate`;
      2. the per-run bucket (50/s, burst 500) → `run_rate`;
      3. the per-run lifetime cap (10,000 lines / 10 MiB) → `run_cap`, with one `warn` line per run when the cap is first hit.

      An accepted line is:
      - (a) pushed to the run's ring (last 1,000 lines; runs in an LRU bounded by `ring_budget_bytes`, evicting whole least-recently-written runs);
      - (b) emitted as `tracing::event!(target: "ostro::guest", level, run_id, workflow, attempt, guest.fields = <json>, "{message}")`. Under `LogFormat::Json` the fields appear structured (tracing-subscriber json flattens `valuable` or string fields; document what you get);
      - (c) emitted as an OTLP LogRecord via the `opentelemetry` Logger API (`global::logger_provider().logger("ostro.guest")`) with body = message, severity mapped, attributes = every guest field + `run.id`/`workflow`/`attempt`, and trace context ids.
    - Metrics: `ostro_guest_log_lines_total{level}` and `ostro_guest_log_dropped_total{reason}` (reasons: activation_bound, node_rate, run_rate, run_cap).
    - Limiter state is per run id, in memory, with LRU cleanup when a run completes or ages out (documented: lifetime caps reset on restart).
    - Unit tests for buckets (FakeClock), caps, ring LRU eviction and field round trip.
  </behavior>
