```rust
#[async_trait] pub trait ObjectStore: Send + Sync + 'static {
  async fn put(&self, key: &str, body: Bytes) -> Result<PutOutcome>;                    // PutOutcome { e_tag: Option<String> }
  async fn put_if_absent(&self, key: &str, body: Bytes) -> Result<Conditional<PutOutcome>>; // If-None-Match: *
  async fn put_if_match(&self, key: &str, body: Bytes, e_tag: &str) -> Result<Conditional<PutOutcome>>;
  async fn get(&self, key: &str) -> Result<Option<(Bytes, ObjectMeta)>>;
  async fn get_range(&self, key: &str, range: std::ops::Range<u64>) -> Result<Bytes>;
  async fn head(&self, key: &str) -> Result<Option<ObjectMeta>>;
  async fn list(&self, prefix: &str, start_after: Option<&str>) -> Result<Vec<ObjectMeta>>; // paginates internally, key order
  async fn delete(&self, key: &str) -> Result<()>;            // idempotent
  async fn delete_many(&self, keys: &[String]) -> Result<()>;
  /// Object-safe (B1): a boxed stream, never `impl Stream`. Default impl collects then calls `put`;
  /// S3 overrides with CreateMultipartUpload/UploadPart(≥ 64 MiB)/Complete (Abort on error); LocalFs overrides by streaming to tmp.
  async fn put_multipart(&self, key: &str, body: futures_core::stream::BoxStream<'static, Result<Bytes>>) -> Result<PutOutcome> {
      /* default: collect into BytesMut, then self.put(key, buf.freeze()) */
  }
  fn supports_conditional_put(&self) -> bool;                 // false → callers use the LOCK re-read fallback (P8-D4)
}
pub struct ObjectMeta { pub key: String, pub size: u64, pub last_modified: jiff::Timestamp, pub e_tag: Option<String>, pub version: Option<String> }
pub enum Conditional<T> { Ok(T), PreconditionFailed }
pub fn open_url(url: &str, cfg: &StoreOptions) -> Result<Arc<dyn ObjectStore>>; // s3://bucket/prefix | file:///abs/path
```
**These signatures are FROZEN by this plan and match 06-02** (the coordinator mirrors this text into 06-02). A compile test asserts object safety: `fn _assert(_: Arc<dyn ObjectStore>) {}` plus a `let _: Arc<dyn ObjectStore> = open_url(..)?`. Phase 6 adds **only** `put_with(key, body, &PutOpts)` and `presign(..)` (06-12), **each with a default impl** (`put_with` → `put`; `presign` → `Ok(None)`), so neither phase breaks the other's implementors. If 06-12 describes other shapes (e.g. `GetResult`/`ListPage`), the signatures above win; record any divergence found in the SUMMARY.
`StoreOptions` mirrors `ostro_backup::config::BackupConfig` transport fields (region, endpoint, url_style, credentials, allow_http, tls_roots). ostro-objstore must not depend on ostro-backup; 08-13 maps one onto the other.

      - put → get → bytes/size/etag;
      - `get_range` (middle, open-ended clamp);
      - `head` of missing → None;
      - `list` with prefix + start_after returns keys in lexicographic order across > 1000 objects (pagination);
      - delete is idempotent; delete_many;
      - `put_if_absent` twice → Ok then PreconditionFailed;
      - `put_if_match` with a stale etag → PreconditionFailed, with the current etag → Ok + new etag;
      - `put_multipart` through `Arc<dyn ObjectStore>` (object safety) with a boxed stream; the default impl is exercised by a test-only backend that does not override it;
      - multipart of 70 MiB round-trips (S3 legs only when `OSTRO_TEST_S3_BIG=1`; LocalFs streams to tmp).
    - LocalFs:
      - keys map to paths under the root (reject `..`, absolute keys and NUL);
      - writes use tmp + `sync_all` + rename + parent dir fsync;
      - conditional ops are serialised by a per-store mutex;
      - etag = hex sha256 of the content;
      - `list` walks in key order.
    - S3:
      - rusty-s3 `Bucket` (path or virtual-host style, region, custom endpoint for MinIO/R2/GCS-interop);
      - credentials, with an optional session token;
      - every action is signed with a short expiry (60 s) and sent with reqwest;
      - conditional headers go through `headers_mut()` **before signing**, and a test asserts that MinIO rejects a mismatched If-Match (proves the signed header reaches the server);
      - retries with exponential backoff + jitter on 5xx/429/timeouts (max 5), never on 412 or 4xx;
      - `allow_http` is required for `http://` endpoints;
      - TLS roots per `tls_roots` (platform by default; webpki or a CA file via the reqwest builder);
      - `supports_conditional_put()` is true by default, and an option `conditional_put = false` forces the fallback.
    - `open_url`: `file:///abs` → LocalFs; `s3://bucket/prefix` → S3 with the prefix prepended to every key. Anything else → error.
