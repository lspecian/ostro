<interfaces>
ostro-cli client (05-14 + 10-03):
- `Client::new(server, timeout)` accepts `http://host:port[/prefix]` or `host:port`; https is rejected until SEC-01.
- Methods return `Result<Response { status, body: Value }, CallError>`. `CallError::Api { status, body }` keeps the server error body; a transport error reads "cannot reach the Ostro server at URL: …".
- Long polls use `timeout + wait` as the request timeout.

ROUTES table convention (D-P10-8). The Python/TS/Go clients (10-11) each declare their routes as a literal table that the contract test reads:
- Python `clients/python/ostro_client/routes.py`: `ROUTES = [("GET", "/v1/runs/{id}"), ...]`;
- TS `clients/ts/src/routes.js`: `export const ROUTES = [["GET", "/v1/runs/{id}"], ...]`;
- Go `clients/go/ostro/routes.go`: `var Routes = [][2]string{{"GET", "/v1/runs/{id}"}, ...}`.

The test parses them with a regex over `("METHOD", "/path")` pairs. A file that does not exist yet (10-11 is wave 4) is reported as "pending" and does not fail. The 10-17 gate requires all four to be present.
</interfaces>
