## Shared files (cross-phase and intra-phase)

Phase 10 runs after Phase 9. Phase 7/8 plans may still be in flight, and **Phase 11 runs in parallel** (ROADMAP: "can run in parallel with Phases 9–10").

**Rule for every row:**
- Before the first edit, `git status --porcelain -- <file>` in the main checkout must show no change by another executor for that path. Paths already shown as deleted (`D`) or modified because other executors commit from worktrees count as clean only when the blob at HEAD is what you build on; build from the HEAD blob in your worktree.
- Record `base=$(git rev-parse HEAD)` before editing. Before committing, check `git diff --quiet "$base" HEAD -- <file>`. If another phase committed to the file meanwhile, re-apply your hunk on the new HEAD content in your worktree, rebuild and re-test.
- Append only, minimal diffs, never reformat or renumber. If you cannot re-apply cleanly, STOP and report the contention.

## Commit procedure (every plan)

Executors share one checkout with Phase 7/8/11 executors. Edits, builds and tests happen in a **scratch worktree under /tmp**, never inside the repo. Commits go through a **private index** in the main checkout and add only the plan's own files.

```bash
REPO=/home/lspecian/Development/ostro
WT=/tmp/ostro-wt-10-NN                      # once per plan; never inside $REPO
git -C "$REPO" worktree add --detach "$WT" HEAD
export CARGO_TARGET_DIR=/tmp/ostro-target-10-NN   # per plan, avoids lock contention between parallel plans
# ... edit, build, test inside "$WT" (all <verify> commands run from "$WT") ...
cd "$REPO"; base_check() { for f in "$@"; do git diff --quiet "$base" HEAD -- "$f" || echo "MOVED $f"; done; }
idx="$(git rev-parse --git-dir)/index-10-NN"; rm -f "$idx"
GIT_INDEX_FILE="$idx" git read-tree HEAD
for f in <this task's files, listed explicitly>; do
  if [ -e "$WT/$f" ]; then mode=100644; [ -x "$WT/$f" ] && mode=100755
    GIT_INDEX_FILE="$idx" git update-index --add --cacheinfo "$mode,$(git hash-object -w -- "$WT/$f"),$f"
  else GIT_INDEX_FILE="$idx" git update-index --force-remove -- "$f"; fi
done
GIT_INDEX_FILE="$idx" git commit -q -F "$msgfile"     # message ends with the Co-Authored-By line
rm -f "$idx"; git reset -q -- <the same files>        # resync the shared index for these paths only
git show --stat HEAD                                   # exactly this task's files
# next task: git -C "$WT" checkout -q --detach "$(git -C "$REPO" rev-parse HEAD)"  (worktree files equal HEAD for own paths)
# end of plan: git -C "$REPO" worktree remove --force "$WT"
```

zsh does not word-split unquoted variables, so use an explicit array (`files=(a b c)`, `"${files[@]}"`) or run the loop under `bash`.

**Never:**
- `git add -A`, `git add .`, `git add -u`, `git commit -a`;
- `git stash`;
- `git checkout -- <path>` on files you do not own;
- `git reset --hard`;
- a commit made from inside the repo's working tree.

Messages end with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`. No remotes, no pushes, no package publishing. Never run the gsd-tools mutators: `state advance-plan`, `roadmap update-plan-progress`, `phase complete`, `requirements mark-complete`, `commit`.
