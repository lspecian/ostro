  <action>
- **`watch.rs`:** `run_watch(opts: WatchOptions, server: String, shutdown)`. Do an initial `deploy_project`. Create a `notify_debouncer_full::new_debouncer(Duration::from_millis(250), None, tx)` on the dir (recursive), and filter events through `ostro_build::pipeline::IGNORE` plus the editor temp patterns. The state machine is `Idle | Building { dirty: bool }`: an event during a build sets `dirty`, and after the build, if `dirty`, build once more. Build and deploy run on a dedicated task so the server is never blocked. Errors print diagnostics with the prefix `ostro dev: build failed; keeping v<N>` and never exit the process. After a successful deploy, print `ostro dev: deployed <workflow> v<N>; new runs use v<N>`.
