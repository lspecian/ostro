  <behavior>
    - The cache root follows OSTRO_TOOLCHAIN_DIR, then XDG_CACHE_HOME, then HOME on Linux. On macOS it is HOME/Library/Caches/ostro/toolchains (cfg-gated unit test with env injection, no global env mutation: resolve takes an env lookup fn)
    - good.tar.gz with the correct pin installs into `<root>/<tool>-<version>-<sha8>/`, with `.ok` present and the executable bit kept. A second ensure makes 0 requests (fixture counter)
    - badsha.tar.gz → Err(ShaMismatch{expected, actual}). No entry dir and no `.tmp-*` remain
    - traversal, abs and symlink-escape archives → Err(UnsafeArchive{entry}), and nothing is written outside the temp dir. symlink-ok installs and resolves inside the entry
    - .tar.xz installs (lzma-rust2 path)
    - A Wheel pin is downloaded and verified and stored as `<entry>/<file>.whl` without extraction
    - offline=true with a cached entry → Ok with 0 requests. Offline with an uncached entry → Err(Offline{tool}), with 0 requests
    - mirror = fixture base B2 (a second fixture instance with the same files) → the request goes to B2 and the sha is still checked. A mirror serving different bytes → ShaMismatch
    - Two concurrent `ensure` calls (tokio::join!) for one pin → one request and both Ok, under `tokio::time::timeout(30 s)`. Two separate `Cache` handles on the same root in one process also serialise (the process-wide mutex), with no deadlock
    - symlink-chain.tar.gz (`a -> b`, `b -> ../../outside`) → UnsafeArchive (checked against the canonical on-disk parent). hardlink-escape.tar.gz → UnsafeArchive (target resolved against the archive root)
    - big.bin with a pin max_bytes smaller than the body → Err(TooLarge), and the temp file is removed. slow.bin with a test read-idle timeout of 1 s → Err(Timeout) within 5 s
    - prune with a stale `tools/` entry and a `state/` dir → removes only the tools entry; `prune --state` also clears state; both run under the lock
    - An interrupted install (a leftover `.tmp-123` dir from a dead pid) is cleaned up on the next ensure
  </behavior>
  <action>
- **`cache.rs`:** `Cache::resolve_with(env: impl Fn(&str) -> Option<String>, os)` plus `resolve()`.
  - `lock().await` first takes the process-wide async mutex for the canonical root, then the exclusive `File::lock` on `<root>/.lock` (via `spawn_blocking`, or a `try_lock` loop with `tokio::time::sleep`), held for the whole install. Never call a blocking lock on a runtime thread.
  - Layout: `tools/` for artefacts, `state/` for builder state (`Cache::state_dir(name)`), with `prune(keep, include_state)`.
  - `entry_dir(pin)` returns `<tool>-<version>-<sha8>`.
  - `is_installed(pin)` checks that `.ok` exists and contains the full pin sha.
  - `.tmp-<pid>-<n>` dirs whose pid is not alive (`/proc/<pid>` on Linux; on macOS `kill(pid, 0)` is not available without libc, so treat dirs older than 1 h as stale) are removed on lock.
- **`fetch.rs`:** `download_verified(client, url, expected_sha, max_bytes, dest_file)` streams chunks into a file while updating `Sha256`. It enforces the size cap and the timeouts (reqwest `connect_timeout(30 s)`, per-chunk idle `tokio::time::timeout(60 s)`, total 15 min; all configurable through `FetchOptions` for tests). It compares at the end, and a mismatch deletes the file. URL rewriting for the mirror is `mirror.trim_end_matches('/') + "/" + <path after the host>`. `offline` short-circuits before any request.
- **`extract.rs`:** `extract(archive, kind, dest)`.
  - TarGz uses flate2 `GzDecoder` and TarXz uses lzma-rust2's XZ reader, both through `tar::Archive`. For each entry, reject:
    - absolute paths;
    - any `..` component;
    - symlink/hardlink targets that are absolute or resolve outside `dest` (lexically normalise `entry_parent.join(target)`).
  - Symlink targets: after extracting the parent dirs, canonicalise the on-disk parent and check that `canonical_parent.join(target)` (lexically normalised) stays under the canonical `dest`. Hardlink targets are resolved relative to the archive root (`dest.join(link_name)`), not to the entry's parent.
  - Then call `entry.unpack_in(dest)` (it returns false on an unsafe path, which is an error). Keep the mode bits.
  - Binary: copy and chmod 0755. Wheel: copy as is.
  - Optional `strip` drops a leading dir component, as Node tarballs need `node-v24.x-linux-x64/`.
- **`cache::install(pin)`:** lock, re-check `is_installed` (a concurrent winner), download into `.tmp`, extract into `.tmp/entry`, write `.ok`, `rename` to the final dir, unlock.

Write the tests first against the 10-02 fixture server, then implement.
