## Commit procedure (every plan)

Executors share one working tree with Phase 7/8 executors, so commits go through a **private index** and add only the plan's own files:

```bash
idx="$(git rev-parse --git-dir)/index-09-NN"; rm -f "$idx"
GIT_INDEX_FILE="$idx" git read-tree HEAD
GIT_INDEX_FILE="$idx" git add -- <this task's files, listed explicitly>
GIT_INDEX_FILE="$idx" git commit -q -F "$msgfile"   # message ends with the Co-Authored-By line
rm -f "$idx"; git reset -q -- <the same files>       # resync the shared index for these paths only
```

Never `git add -A`, `git add .`, `git add -u`, `git commit -a`, `git stash`, `git checkout -- <path>` on files you do not own, or `git reset --hard`. Messages end with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`. No remotes, no pushes, no package publishing.
