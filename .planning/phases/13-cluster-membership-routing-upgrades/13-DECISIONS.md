## Worktree + commit procedure (every plan; the 11-DECISIONS procedure adapted, plan check B3)

Executors share one checkout. Edits, builds and tests happen in a **per-plan scratch worktree under /tmp**, never inside the repo. Commits go through a **private index** in the main checkout and add only the plan's own files.

```bash
REPO=<repo>
WT=/tmp/ostro-wt-13-NN                      # once per plan; never inside $REPO
git -C "$REPO" worktree add --detach "$WT" HEAD
base=$(git -C "$REPO" rev-parse HEAD); echo "$base" > "$(git -C "$WT" rev-parse --git-dir)/p13-base"
export CARGO_TARGET_DIR=/tmp/ostro-target-13-NN   # per plan, avoids lock contention between parallel plans
# ... edit, build, test inside "$WT" (every <verify> command runs from "$WT") ...
cd "$REPO"; for f in <own files>; do git diff --quiet "$base" HEAD -- "$f" || echo "MOVED $f"; done   # MOVED → re-apply on the new HEAD first
idx="$(git rev-parse --git-dir)/index-13-NN"; rm -f "$idx"
GIT_INDEX_FILE="$idx" git read-tree HEAD
for f in <this task's files, listed explicitly>; do
  if [ -e "$WT/$f" ]; then mode=100644; [ -x "$WT/$f" ] && mode=100755
    GIT_INDEX_FILE="$idx" git update-index --add --cacheinfo "$mode,$(git hash-object -w -- "$WT/$f"),$f"
  else GIT_INDEX_FILE="$idx" git update-index --force-remove -- "$f"; fi
done
for f in <own files>; do git diff --quiet "$base" HEAD -- "$f" || { echo "MOVED at final HEAD: $f"; exit 1; }; done   # re-check right before committing
GIT_INDEX_FILE="$idx" git commit -q -F "$msgfile"     # message ends with the Co-Authored-By line
rm -f "$idx"; git reset -q -- <the same files>        # resync the shared index for these paths only
git show --stat HEAD                                   # exactly this task's files
# next task: git -C "$WT" checkout -q --detach "$(git -C "$REPO" rev-parse HEAD)"; refresh p13-base
# end of plan: git -C "$REPO" worktree remove --force "$WT"
```

- zsh does not word-split unquoted variables: use an explicit array or run the loop under `bash`.
- **The shared checkout's working tree is never written** by an executor (not even `git checkout -- <path>`), so other agents' stale blobs are left alone.
- **Stale-blob rule:** the shared checkout lags behind HEAD because every agent commits through private indexes, so `git status` there shows many stale blobs. A path counts as **contention** only if its working-tree blob in the shared checkout matches **no** recent commit (`git hash-object <f>` vs `git rev-parse <c>:<f>` for the last 20 commits touching `<f>`). A stale blob is not contention. Contention means STOP and report.
- Plan-level gates (`bash scripts/ci-local.sh --no-musl`) run in `$WT` at the plan's last commit (after `git -C "$WT" checkout -q --detach <that commit>`); record the commit and step timings in the SUMMARY.
- Verify commands: `set -euo pipefail`, cargo test filters after `--`, a filtered run must report ≥ 1 passed test, and negations are written `if cmd; then exit 1; fi` (never a mid-script `! cmd`, which `set -e` ignores; plan check B7).
- Never `git add -A`, `git add .`, `git add -u`, `git commit -a`, `git stash` or `git reset --hard`. Messages end with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`. No remotes, no pushes. Never run gsd-tools mutators (`state advance-plan`, `roadmap update-plan-progress`, `phase complete`, `requirements mark-complete`, `commit`).
