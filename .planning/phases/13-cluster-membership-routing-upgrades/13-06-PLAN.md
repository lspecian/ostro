  <behavior>
    Reconciler cases (unit tables, then the model):
    - voters_outgoing = {3}, no pending → LeaveJoint; pending → None.
    - joining member 4 not in conf → AddLearner(4).
    - 3 live Active members, voters {1}, learners {2,3} both caught up → Joint{add [2,3]} (one joint change, 1 → 3); only one caught up → None (wait); 2 members → voters stay 1 (largest odd ≤ 2).
    - 5 live members, voters {1,2,3}, learners {4,5} caught up → Joint{add [4,5]} (3 → 5); 6 members → 5 voters + 1 learner; max_voters 5 enforced.
    - removing voter 3 with voters {1,2,3}, no ready learner, live {1,2,3} → Joint{remove [3], demote [2]} (3 → 1, odd at rest); live {1,3} → None (the new config must have a live quorum); removing two of 5 voters → one Joint{remove [a,b]}.
    - removing self while meta leader → TransferLeader(best caught-up live voter).
    - lagging learner (matched < commit − promote_lag) or pending snapshot → not promoted.
    - removing a voter while a learner is ready → Joint{add [l], remove [v]} (Auto transition); a Removed learner → RemoveLearner(id).
    Model invariants (proptest-state-machine, ≥ 1000 cases in release): every non-joint config has an odd voter count and both halves of every joint config are odd; ≤ 1 pending change; never a Remove that breaks live quorum; joint state always eventually left; removed ids never re-added (tombstones).
    Placement invariants (proptest over 1–7 nodes, P ∈ {4, 16, 64}, RF 1–3, random initial assignment incl. a promoted RF=1 cluster): no duplicate replica per partition; |replicas| = min(rf, active nodes); counts differ ≤ 1; preferred leaders differ ≤ 1; draining nodes hold 0 replicas after the plan; plan from an already balanced assignment is empty (minimal moves).
    Reassign invariants: from any state, min_insync ≤ |isr| on every emitted AlterReplicas; Shrink is the only step that raises min_insync and is emitted only when target ⊆ published ISR; no emitted AlterReplicas lowers min_insync below min(policy, |target|) (model case `shrink_waits_for_target_in_isr` with a lagging target member); LeaderMove only to an in-ISR member of target; cancel restores old replicas; replicas ⊇ isr always.
    Leaders: at most one move; only to an in-ISR preferred replica; no move when balanced.
