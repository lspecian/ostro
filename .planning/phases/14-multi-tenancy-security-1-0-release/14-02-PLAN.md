    - Unauthenticated (no authenticate call): `/healthz`, `/readyz`, `/metrics`, `POST /hooks/*`, `POST /v1/workers/join`, `POST /v1/cluster/join`, **`/ui/**` (the whole UI tree: `UiAuth` owns UI authentication and wraps UI handlers in `PRINCIPAL.scope`, 14-21)**, and the gRPC equivalents `grpc.health.v1.Health/*` and `ostro.api.v1.Cluster/Join`. **Principal for these routes (B2):** `POST /hooks/*` and the two join routes (REST + gRPC) run inside an explicit `PRINCIPAL.scope(Principal::system(), …)`; health, metrics and `/ui/**` run with no scope, so `auth::current()` is `Anonymous` (no scopes, denied by the guard) unless UiAuth sets one.
