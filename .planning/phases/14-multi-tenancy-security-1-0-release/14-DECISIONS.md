## Commit procedure (every plan; durable executor brief, revision 2026-11-26)

The binding procedure is the **durable executor brief** (`/home/lspecian/.local/share/ostro-orchestrator/exec-brief.md`, "Working copy and commits"); it replaces the `/tmp` worktree procedure planned on 2026-11-19. In short:

```bash
REPO=/home/lspecian/Development/ostro
WT=/home/lspecian/.local/share/ostro-orchestrator/wt/14-NN          # never /tmp, never the stale main checkout
git -C "$REPO" worktree add --detach "$WT" main

export CARGO_TARGET_DIR=$REPO/target/slot-N CARGO_INCREMENTAL=0 CARGO_BUILD_JOBS=6   # the assigned slot; `nice -n 10`; cargo's CACHEDIR.TAG present
# ... edit, build, targeted tests inside "$WT"; heavy suites via ostro-k8s-ci (below) ...
export GIT_INDEX_FILE=/home/lspecian/.local/share/ostro-orchestrator/idx-14-NN
OLD=$(git -C "$REPO" rev-parse refs/heads/main)
# commit only this task's files (explicit list) on top of OLD; if main moved, rebuild the commit on OLD first
git merge-base --is-ancestor "$OLD" "$NEW"                              # never drop others' commits
test -n "$(git diff-tree --no-commit-id --name-only -r "$NEW")"          # non-empty
git -C "$REPO" update-ref refs/heads/main "$NEW" "$OLD"                  # CAS
# end of plan: git worktree remove; rm the private index; empty target/slot-N (cargo clean)
```
