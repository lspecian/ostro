## Commit procedure (every plan; worktree-only, Phase 11 procedure)

Edits, builds and tests happen in the plan's own **scratch worktree under /tmp**, never in the shared checkout. Commits go through a **private index** and add only the plan's own files.

```bash
REPO=<repo>
WT=/tmp/ostro-wt-14-NN                      # once per plan; never inside $REPO
git -C "$REPO" worktree add --detach "$WT" HEAD
base=$(git -C "$REPO" rev-parse HEAD); echo "$base" > "$(git -C "$WT" rev-parse --git-dir)/p14-base"
export CARGO_TARGET_DIR=/tmp/ostro-target-14-NN
# ... edit, build, test inside "$WT" (all <verify> commands run from "$WT") ...
cd "$REPO"; for f in <own files>; do git diff --quiet "$base" HEAD -- "$f" || echo "MOVED $f"; done   # MOVED → re-apply on the new HEAD first
idx="$(git rev-parse --git-dir)/index-14-NN"; rm -f "$idx"
GIT_INDEX_FILE="$idx" git read-tree HEAD
for f in <this task's files, listed explicitly>; do
  if [ -e "$WT/$f" ]; then mode=100644; [ -x "$WT/$f" ] && mode=100755
    GIT_INDEX_FILE="$idx" git update-index --add --cacheinfo "$mode,$(git hash-object -w -- "$WT/$f"),$f"
  else GIT_INDEX_FILE="$idx" git update-index --force-remove -- "$f"; fi
done
GIT_INDEX_FILE="$idx" git commit -q -F "$msgfile"     # message ends with the Co-Authored-By line
rm -f "$idx"
git show --stat HEAD                                   # exactly this task's files
# next task: git -C "$WT" checkout -q --detach "$(git -C "$REPO" rev-parse HEAD)"; refresh p14-base
# end of plan: git -C "$REPO" worktree remove --force "$WT"
```

- **Stale-blob rule:** the shared checkout lags behind HEAD (private-index commits), so `git status` there shows stale blobs. A path is **contention** only if its working-tree blob matches **no** recent commit (`git hash-object <f>` vs `git rev-parse <c>:<f>` for the last 20 commits touching `<f>`). Contention → STOP and report.
- **Final-HEAD re-check:** immediately before each commit, if `git -C "$REPO" rev-parse HEAD` ≠ `base` and an own file moved, save the plan diff, move the worktree to the new HEAD, `git apply --3way`, rebuild and re-run the task verify; repeat until HEAD is stable.
- The shared index is never used for commits and the shared working tree is never written (not even `git checkout -- <path>` or `git reset -- <path>` on files another agent has staged).
- zsh does not word-split unquoted variables: run loops under `bash`.
- Never `git add -A`, `git add .`, `git add -u`, `git commit -a`, `git stash` or `git reset --hard`. Messages end with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`. No remotes, no pushes; tags stay local. Never run gsd-tools mutators (`state advance-plan`, `roadmap update-plan-progress`, `phase complete`, `requirements mark-complete`, `commit`).
