  <behavior>
    - `history.rs`: append-only JSONL of client ops `{op_id, kind: start|signal|result|cancel, node, invoke_ms, complete_ms, outcome: ok|fail|info(unknown), run_id, idem_key, consistency_token}` plus nemesis events `{kind, target, start_ms, end_ms}`; `info` (timeout/connection reset) ops are indeterminate and never counted as lost.

    - `duplicate.rs`: from exported per-replica logs and journals: no `(run, seq)` journaled twice; replica logs byte-identical up to the minimum HW (reuse the Phase 12 replica-identity oracle where possible).

    - Self-tests (pure, synthetic inputs built in the test): each checker passes on a clean synthetic run and reports exactly the injected anomaly (lost ack; duplicate seq; divergent replica entry; two leaders same epoch; acked offset overwritten after truncation; stale token accepted).
