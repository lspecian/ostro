      - a missing `outcome` → Invalid(BadEffectCompletion).

      An outcome that is a blob PayloadRef is stored as a blob payload exactly as EventsAppended stores a blob event payload. A test uses a > 256 KiB outcome and checks that the stored event decodes (in the test, not in apply) to the original `EffectCompleted`.
