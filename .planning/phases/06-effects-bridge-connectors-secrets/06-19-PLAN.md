  <action>
Implement:
- `Canary::new()`: a random value; `Debug` prints `Canary(<redacted>)`.
- `Canary::needles()`: raw; standard and URL-safe base64, padded and unpadded, each at byte offsets 0/1/2 (encode `prefix_k || canary` and take the stable middle substring); lower/upper hex; percent-encoded (all bytes, and the unreserved-preserving form); JSON-escaped.

- `scan_tree(dir) -> Vec<Hit>`, which walks every regular file (follows no symlinks) and reads it fully.
- `CaptureLayer`: a `tracing_subscriber::Layer` recording every event's and span's fields (formatted with `Debug` and `Display` visitors) at TRACE into a shared buffer; `CaptureLayer::install_global()` (OnceLock) and `captured() -> Vec<u8>`.
- `register_sink(name, Box<dyn Fn() -> Vec<u8> + Send + Sync>)` plus `scan_sinks(&Canary)`: the hook Phase 8 uses for an OTLP mock collector (document D-FX6).
- `Report`, aggregating hits, with `assert_clean()` that panics with location/encoding only.
- `spawn_quiet(fut)`: runs a future on a new OS thread with its own tokio runtime and a thread-local `NoSubscriber` default, so the mock servers' tracing never reaches `CaptureLayer` (W6). fx_canary, fx_object_e2e and fx_providers_e2e start every mock through it.

Add unit tests: each needle form is detected when embedded in noise, and a value differing by one byte is not.

**Mocks must not pollute the capture (W6):** the MockProvider, the Vault mock and the K8s mock legitimately see the canary. Run them on a **separate OS thread with its own tokio runtime**, and inside that thread set `tracing::subscriber::set_default(tracing::subscriber::NoSubscriber::default())` (a thread-local default overrides the global one), so nothing they log reaches `CaptureLayer`. Also give `CaptureLayer` a target filter that drops events whose target starts with `ostro_testkit::mock` and `axum`/`hyper` server spans from the mock thread, as a second guard. Add a control assertion: an event logged by the server under test with a known marker string *is* captured, so the scan cannot pass vacuously. Start the server with a temp data dir and a local object connection rooted in the temp dir (so the object-store root is scanned too). Configure through REST:
- secret `canary-key` = the canary value;
- a grant for module fx-canary → the mock origin (no body);
- egress for the mock origin;
- a second secret `other-key` granted only to `https://elsewhere.test`.

Cases:
1. **leak scan**: run fx-canary against `/echo` with header `X-Api-Key: Bearer {{secret:canary-key}}`, and also run one fx-object put/get of non-secret data so the object root exists. Wait until terminal. Collect:
   - every REST response body the test received (runs, history, secrets list, connections list);
   - the gRPC list responses;
   - the guest output (observed response, env, args, random);
   - the decoded journal (`history` JSON and the raw events from the store via the export tool or a direct read);
   - `CaptureLayer::captured()`;
   - `scan_sinks`;
   - after a clean shutdown, `scan_tree(data_dir)` (WAL, state, meta, blobs) and `scan_tree(object_root)`.
