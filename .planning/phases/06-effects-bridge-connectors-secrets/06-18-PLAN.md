For each dialect (PG via `db::pg()`, MySQL via `db::mysql()`; skip loudly when None):
1. Create the user table `orders(run_id text/varchar(64) primary key, amount bigint)` in the test schema/database.
2. Spawn `CARGO_BIN_EXE_ostro dev` on a temp data dir with `FAILPOINTS=bridge::sql::after_commit=return(hang)`. Deploy fx-sql. Configure through REST:
   - a connection `orders` of the dialect's kind (password via a sealed secret if the URL has one, otherwise none). For PG, set the connection config **`"schema": <PgTestDb::schema()>`** (06-11 applies it as search_path through connect options), so each test is isolated in its own `t_<uuid>` schema (W3). For MySQL, use the per-test database;
   - `"pool_max": 60`, so even if a held effect kept a connection, 50 held effects would not exhaust the pool. 06-11 already returns the connection before `after_commit` fires (W4); the test also asserts the pool stayed usable while the 50 effects are held, using an `exactly_once=false` statement through the connector (or a plain query on its own test pool). The autocommit path does not pass through the process-wide `bridge::sql::after_commit` failpoint, which applies to exactly-once statements only;
   - egress `connection:orders` for the module.
3. Start 50 runs, each executing `INSERT INTO orders(run_id, amount) VALUES ($1, $2)` exactly-once with its own run id parameter (MySQL uses `?` placeholders).
4. Poll the DB until `SELECT count(*) FROM ostro_effects WHERE result IS NOT NULL` = 50 (all committed and held), with a 60 s timeout.
5. kill -9. Restart without FAILPOINTS. Wait until all 50 runs are terminal.
6. Assert:
   - `SELECT count(*) FROM orders` = 50;
   - each run's output (fx-sql JSON) shows `rows_affected = 1`;
   - each run's journaled EffectCompleted result bytes equal the `ostro_effects.result` for its key (via the history API plus a DB query).
7. Repeat once with `bridge::sql::before_user_stmt=return(hang)` (token inserted but not committed → rolled back by the crash). After restart: exactly 50 rows.

Print the wall times. Test names: `pg_after_commit`, `pg_before_user_stmt`, `mysql_after_commit`, `mysql_before_user_stmt`.
