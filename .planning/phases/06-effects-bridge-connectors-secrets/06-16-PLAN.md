  <name>Task 1: Server ControlPlane bridge methods + presign route impl</name>
  <files>crates/ostro-server/src/control/bridge.rs, crates/ostro-server/src/control/mod.rs, crates/ostro-server/tests/bridge_admin.rs</files>
  <behavior>
    - `put_secret`:
      - validate the name (template grammar, no `__ostro/`) and value length ≥ 8;
      - no sealing key (server mode) → `ApiError` 409/412 with code `sealing_key_missing` and the message "set OSTRO_SEALING_KEY or [secrets] sealing_key_file";
      - otherwise `seal("<tenant|_>/<name>", value)` → meta put → `SecretInfo{name, key_id}`.

      `list_secrets` returns names and key_ids only (hides `__ostro/*`). `delete_secret` refuses `__ostro/*`.
    - `put_grant`: build a `GrantSpec` (validate origin patterns), store `to_record()`, return GrantInfo with the computed id. `list_grants(module)` filters by the subject. `delete_grant(id)` accepts only ids with the `secret:` prefix.
    - `put_connection`: validate the kind and `config.v == 1`. For `http-target`, the name must be a normalised origin (`Origin` round-trips it); for sql-*/object, parse with the bridge config parsers (`sql::config`, `object::config`), surfacing errors as 400. Store the JSON bytes. get/list return the config verbatim (templates are not secrets).
    - `put_egress`: every entry parses via `parse_rule` (including `connection:<name>`). Store `EgressPolicy{name: module, allow}`.
    - `presigned_object` → `ObjectConnector::serve_local(...)`, mapping Expired/BadSignature → 403, NotFound → 404, a non-local backend → 400.
    - bridge_admin.rs (in-process server; REST via reqwest and gRPC via the tonic clients):
      - a full CRUD round-trip for all four resources;
      - a canary secret PUT, then a scan of every list/get response (REST + gRPC) and of the meta snapshot bytes on disk for the raw canary → absent (it is sealed);
      - `__ostro/x` → 400; a 7-byte value → 400;
      - server profile without a key → `sealing_key_missing`;
      - local presign: create an object connection (local root tempdir), produce a presigned URL through `ObjectConnector` (a helper), then GET it without auth → 200, tampered → 403, expired → 403.
  </behavior>
