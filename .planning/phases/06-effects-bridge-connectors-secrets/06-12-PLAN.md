  <behavior>
    - LocalFs:
      - keys map to `<root>/<key>`; `..` segments and absolute keys are rejected with `Error::Config`;
      - `put` writes `<dir>/.tmp-<uuid>`, fsyncs, renames and fsyncs the dir; `put_with` stores `content_type` in a sidecar `<key>.ostro-meta.json` (excluded from `list`);
      - `head` returns the size, `last_modified` from the mtime as `jiff::Timestamp` and `e_tag` = hex sha256 of the content (computed at put, stored in the sidecar);
      - `list` returns every object after `start_after` in key order (`Vec<ObjectMeta>`);
      - `get`/`head` of a missing key → `Ok(None)`; `delete` of a missing key → `Ok(())`; `delete_many` loops;
      - `put_if_absent`/`put_if_match` are emulated under a process mutex (or stubbed `Unsupported` if Phase 8 owns them; record which);
      - `presign` → `Ok(None)`.
    - S3Store:
      - sign each action with rusty-s3 and send via the injected reqwest client;
      - 404 on get/head → `Ok(None)`, 412 on conditional put → `Conditional::PreconditionFailed`, other non-2xx → `Error::Status{code, body (truncated 1 KiB)}`;
      - `put_with` sets `content-type` via `headers_mut()`;
      - retry 5xx/transport with backoff (3 attempts);
      - `presign(Get|Put, key, expires, opts)` uses `query_mut()` for `response-content-type` and `headers_mut()` for `content-type` (signed; the uploader must send it), then `.sign(expires)`; expiry is clamped to 1 s..7 d.
    - Tests:

      - presign.rs: LocalFs returns None. For S3 with SeaweedFS env: a presigned GET is fetchable by a plain reqwest client; a presigned PUT with the signed content-type uploads; a URL with a 1 s expiry fails after 2 s.
      - s3.rs (env-gated): put/get/get_range/head/list/delete.
