`activation.rs`: `pub(crate) async fn run_activation(rt: &Runtime, p: &Prepared, mut act: Activate, sink: Arc<dyn ActivationSink>) -> ActivationOutcome`:
1. `HostState::new(HostInit { run, attempt, module_hash_hex, journal: act.journal, clock, limiter: engine.new_limiter(), wall_deadline: Instant::now() + cfg.activation_timeout, token_key, continue_as_new_events, sink: Some(sink.clone()) })` — BadJournal → `AttemptFailed(ProtocolViolation("bad journal: .."))`.
2. `Store::new`, `configure_store(&mut store, cfg.activation_fuel)`; `p.pre.instantiate_async(&mut store)` — error → `AttemptFailed(Trap(engine.explain_instantiate_error(&e)))`.
3. Read workflow name + input from `store.data().replay.run()`. Run `call_run` inside `tokio::select! { r = call => r, _ = act.cancel.cancelled() => external eviction }`; on external cancel drop the call future (fiber disposed), flush pending, outcome `Evicted { External }`.
4. Map the result: `Ok(Ok(RunResult::Completed(p)))` / `ContinueAsNew(c)` / `Ok(Err(failure))` → `record_terminal` (NonDeterminism → AttemptFailed) → flush → `Completed{output}` / `ContinuedAsNew{continuation}` / `Failed{failure}`. `Err(e)` → `classify(&e, store.data())`: `Evict` → flush → `Evicted{reason}`; NonDeterminism → `AttemptFailed(NonDeterminism)` WITHOUT flushing (the journal is not extended by a diverged attempt); every other class → best-effort flush of pending (completed live steps survive the retry) → `AttemptFailed(class)`. A flush error maps: `Fenced` → `ActivationOutcome::Fenced`; `Conflict` → `Evicted{AppendConflict}` (next dispatch replays the committed journal); `Unavailable` → `Evicted{External}`.
5. `sink.done(&run, attempt, outcome.clone()).await` exactly once, then return the outcome. Dropping the Store releases the memory budget (limiter Drop).
`fn classify(e: &wasmtime::Error, st: &HostState) -> Classified` (Research Code Examples "Error classification"): downcast order NonDeterminism → Evict → ProtocolViolation → GuestExit → limiter breach flag (`Breach::Memory`/`Table` → MemoryExceeded; the memory cap is NOT a Trap, Research verified) → `Trap::OutOfFuel` → FuelExhausted, `Trap::Interrupt` → Timeout, `Trap::StackOverflow` → StackOverflow → otherwise `Trap(format!("{:#}", e) + stderr tail if non-empty)` (Rust panic messages arrive on stderr before the `unreachable` trap). Unit-test `classify` with synthetic errors (`wasmtime::Error::new(NonDeterminism{..})`, `wasmtime::Error::new(Trap::OutOfFuel)`, etc.) inside activation.rs.
Emit `metrics::counter!("ostro_activation_outcomes_total", "outcome" => code)` and a histogram of activation duration; `tracing` span per activation with run id/attempt.

`testkit.rs` (compiled only with feature `testkit`; doc: test double for the Phase 2 partition leader):
- `pub struct FakeClock` (impl Clock): starts at a given nanos, advances `step_nanos` (default 1 ms) per call — makes live timestamps, and therefore journals, byte-reproducible.
- `pub struct RunSpec { pub run: RunRef, pub workflow: String, pub input: Payload, pub seed: RngSeed, pub accepted_at_nanos: u64, pub deadline_nanos: Option<u64> }` + `fn run_started_event(&self, module_hash_hex) -> Event` (seq 0).
- `pub enum Rule { CompleteEffects(Arc<dyn Fn(&EffectRequest) -> Result<OpOutput, Failure> + Send + Sync>), Signal { name: String, payload: Payload }, CompleteTokens(Payload), CompleteChildren(Arc<dyn Fn(&str, &Payload) -> Result<OpOutput, Failure> + Send + Sync>), CancelAfterActivations(u32), FenceOnAppend(u32), ConflictOnAppend(u32) }`; `pub struct Script { pub rules: Vec<Rule>, pub max_activations: u32 /* 100 */, pub fire_timers: bool /* true */ }` with builder methods. Defaults when no rule matches: started timers fire on eviction (`TimerFired`), effects complete with `Err(Failure::NonRetryable{ kind: "unsupported", message: "effect bridge lands in Phase 6" })`, children complete with the same "unsupported" failure, signals/tokens stay pending.
- `pub struct FakeSink { state: Mutex<FakeState> }` with `FakeState { journals: HashMap<RunRef, Vec<Event>>, current_attempt: HashMap<RunRef, u32>, batches: Vec<(RunRef, u64, usize)>, done: Vec<(RunRef, u32, ActivationOutcome)>, append_count: u32, script }`. `append`: attempt mismatch → `Fenced`; scripted FenceOnAppend(n)/ConflictOnAppend(n) on the nth append; `from_seq != journal.len()` → `Conflict{expected}`; event seqs must be contiguous from `from_seq` (else Unavailable("bad seqs")); push + record batch; return next seq. `fetch_blob` → Unavailable. `done` → record. Accessors: `journal(&run)`, `batches()`, `outcomes()`, `appended_events(&run)`.
- `pub struct Drive { pub outcome: ActivationOutcome, pub journal: Vec<Event>, pub activations: u32, pub appended_batches: usize, pub latest_status: Option<String> }`.
- `pub async fn drive_to_completion(rt: &Runtime, p: &Prepared, spec: RunSpec, script: Script) -> Drive`: seed the sink journal with RunStarted; loop: `rt.activate(p, Activate { journal: sink.journal(run), inputs: None, cancel: new token, .. }, sink)`; on `Evicted` → compute scripted inputs from the journal (unfired TimerStarted → TimerFired, unanswered EffectScheduled → EffectCompleted via rule/default with `encode_result`, matching SignalWaitStarted → SignalReceived, AwaitTokenCreated → TokenCompleted if CompleteTokens, ChildStarted → ChildCompleted, CancelAfterActivations(n) when activations == n → CancelRequested) appended with the next seqs; if nothing was delivered → return (stuck, outcome Evicted); stop after `max_activations`. Any terminal outcome → return. `latest_status` = json of the last StatusPublished in the journal (WIT-05: the published value comes from the journal).
- `pub async fn replay_journal(rt, p, run: RunRef, journal: Vec<Event>) -> (ActivationOutcome, usize /* events appended */)`: activation over a FakeSink pre-seeded with the full journal; returns the appended event count (0 for a faithful replay of a terminal journal).
