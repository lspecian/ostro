  <behavior>
    - cache_key_stable: `cache_key(&engine, &sha)` is identical across two calls and across two engines built from the same Config, is `hex(sha) + "-" + 16 hex chars`, and differs for an engine with a different config (compat digest differs).
    - compat_digest_env_independent: setting `WASMTIME_BACKTRACE_DETAILS=1` in-process before building a second engine from the same Ostro config does not change the digest (the config sets backtrace details to Disable explicitly; if the test config from common does not, build the config locally with `wasm_backtrace_details(Disable)` and note it for 03-03).
    - hmac_key_created_0600: `load_or_create_key(dir)` creates `dir/aot.key` with 32 random bytes (source: `getrandom` is not a dep — read 32 bytes from `/dev/urandom` on unix, or derive from `std::collections::hash_map::RandomState` + time + pid hashed with sha256 as a portable fallback; document) and mode 0o600 on unix; a second call returns the same key.
    - cache_roundtrip: `put(key, cwasm)` writes `dir/aot/<key>.cwasm` as `cwasm ‖ hmac_sha256(key, cwasm)` via tmp file + fsync + rename; `get(key)` returns `Some(Component)` that instantiates the smoke guest.
    - cache_tamper_detected: flip one byte in the middle of the stored file → `get` returns None (miss), the file is deleted, `stats().tamper_total == 1`, and `metrics::counter!("ostro_aot_cache_tamper_total")` was incremented (assert via the internal stats counter; the metrics call is fire-and-forget). Also flip a byte in the trailer → same.
    - cache_truncated: a file shorter than 32 bytes → miss + deleted, counted as tamper.
  </behavior>
  <action>
Implement in `cache.rs`:
- `struct Sha256Hasher(sha2::Sha256)` implementing `std::hash::Hasher` (`write` feeds the digest, `finish` returns 0 and is unused). `pub fn compat_digest(engine: &wasmtime::Engine) -> [u8; 32]` = sha256 over `engine.precompile_compatibility_hash().hash(&mut h)`, then `"wasmtime=50.0.2"`, `env!("CARGO_PKG_VERSION")` (Ostro version), and the target triple (`std::env::consts::ARCH` + `OS` + target env via `cfg!(target_env = ...)`). Never use `DefaultHasher` (algorithm unspecified across Rust releases).
- `pub fn module_sha(bytes: &[u8]) -> [u8; 32]`; `pub fn cache_key(engine, sha) -> String` = `hex(sha) + "-" + hex(compat_digest)[..16]` (write a tiny hex helper; no hex crate).
- `pub fn load_or_create_key(dir: &Path) -> std::io::Result<[u8; 32]>` (create_new with mode 0o600 via `std::os::unix::fs::OpenOptionsExt` under `#[cfg(unix)]`).
- `pub struct DiskCache { dir: PathBuf, key: [u8; 32], stats: CacheStats }` with `get(&self, engine, key) -> Option<Component>`: read whole file into memory; split trailer; `Hmac<Sha256>::verify_slice` (constant time); mismatch/short → delete file, `tamper_total += 1`, `metrics::counter!("ostro_aot_cache_tamper_total").increment(1)`, `tracing::warn!`, return None; else `unsafe { Component::deserialize(engine, &bytes) }` (SAFETY comment: bytes were produced by `precompile_component` of an engine with the same compat digest and authenticated with the node-local key) — deserialize Err → delete, `incompatible_total += 1`, None. `put(&self, key, cwasm: &[u8]) -> io::Result<()>` (tmp in same dir → write → `sync_all` → rename → fsync dir on unix). Never use `Component::deserialize_file` (TOCTOU between verify and mmap).
- `#[derive(Default)] pub struct CacheStats { pub hits, misses, compiles, tamper_total, incompatible_total: AtomicU64 }` with `snapshot()`.
