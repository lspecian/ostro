# {{name}}

An Ostro durable workflow module in TypeScript, generated by `ostro init --lang ts`.

`src/index.ts` defines one workflow, `hello`. It:

1. runs the durable step `greet`;
2. sleeps for three days (a durable timer that survives restarts and deploys);
3. waits for the signal `approve`;
4. returns `{"greeting": "hello <name>", "approved": <approve.ok>}`.

## Next steps

```sh
ostro dev --watch                                   # local server; rebuilds and redeploys on save
ostro deploy                                        # build target/ostro/{{name}}.wasm and deploy it
ostro run hello --input '{"name":"ada"}' --wait     # start a run and wait for its result
ostro signal <run-id> approve --payload '{"ok":true}'  # from another terminal
```

The run sleeps for three days before it waits for `approve`; `ostro dev --time-skipping`
skips idle time so you can watch it finish now.

## Toolchain

`ostro build` needs no preinstalled toolchain: it downloads a pinned, sha256-verified
Node.js 24 into the Ostro cache and installs the pinned jco toolchain from the lockfile in
`target/ostro/sdk/toolchain/` on first use. Use `ostro build --docker` to build in a
container instead, and `ostro doctor` to see what is installed.

The `ostro` SDK ships as TypeScript sources under `target/ostro/sdk/ts/` (materialised
from the SDK bundle embedded in the `ostro` binary); `tsconfig.json` maps `"ostro"` to it
for your editor, and `ostro build` bundles it. The project has no npm dependencies.
Workflow code runs inside a WebAssembly component: keep I/O in steps and effects
(`ctx.http`, `ctx.sql`, `ctx.object`).

## Testing

```sh
ostro build          # materialises target/ostro/sdk if needed
npm test             # node --test; spawns `ostro dev --ephemeral --time-skipping` (OSTRO_BIN or PATH)
```

`test/workflow.test.js` uses the Ostro test kit (`TestEnv`, imported from the bundled
`ostro-client`). The server skips idle time, so the three-day sleep takes seconds.
